# AI Content Localization Assistant

**面向海外社交媒体运营人员的人工智能内容本地化助手**

事实溯源 · 人工审核门控 · 多模态互动

</div>

## 项目简介

面向 TECNO 尼日利亚 TikTok 内容团队的本地化与审核辅助工具：把中文产品卖点改写为符合目标市场表达习惯的短视频文案，并通过**事实溯源**和**人工审核门控**控制发布风险。

核心设计原则：**不信任生成结果**。AI 负责效率和本地化表达，代码和流程负责事实安全，人只审核真正需要人审核的部分。

## 核心创新

- **服务端证据校验**：每条产品事实必须附带来源原文引用，服务端代码级校验来源是否真实存在于用户提供的资料中；匹配不上的自动降级进"待人工确认"，而不是报错
- **风险分级的人审门控**：可溯源事实进入绿区；无法溯源、模型不确定、命中禁用词的内容全部汇入待审核队列；价格、上市时间等高风险字段永不自动放行
- **防御纵深**：禁用词不只写在 prompt 里，服务端二次检测、强制拦截
- **审核门控跨模态不失效**：图片/视频提取的事实同样过证据链；对话式精修每次在服务端重跑校验，迭代不会绕过审核

## 多模态互动（借鉴 OpenMontage 的 agent 流水线思想）

| 功能 | 说明 |
|---|---|
| 参考素材工坊 | 上传产品图（≤4 张）或本地参考短视频（浏览器自动抽帧），Vision 模型提取可核验的产品事实与创作风格笔记 |
| 分镜卡 Scene Plan | TikTok 脚本自动拆成逐镜头时间轴（画面 / 口播 / 字幕），导出 TXT 同步携带 |
| 口播试听 | 浏览器 TTS 整段或逐镜头朗读脚本，可调语速，零 API 成本 |
| 语音输入 | 浏览器 Web Speech API 口述需求（中文 / 英文），零 API 成本 |
| AI 对话精修 | 对单条结果用一句话迭代，每次修改重新执行证据校验与禁用词检查 |

## 功能列表

- 默认聚焦 TECNO CAMON 40 Pro 5G、Nigeria、TikTok 短视频口播
- 选择目标市场、平台、语气和目标用户
- 根据产品事实生成 20-35 秒社交媒体脚本
- 输出有来源的产品事实和待人工确认内容
- 编辑生成结果并保存为新版本，导出纯文本文件
- API Key 客户端加密存储（localStorage），不上传服务器

## 本地运行

```powershell
npm install
npm run dev
```

浏览器访问 `http://localhost:3000`，在设置中填写兼容 OpenAI 接口的 API Key 和 Base URL（或 Gemini API Key）。

多模态功能建议使用 Gemini 2.5 Flash；语音输入 / 口播试听需要 Chrome 或 Edge。

## 技术栈

- Next.js 16 (App Router) · React 19 · TypeScript · Tailwind CSS · shadcn/ui
- Vercel AI SDK（结构化输出 + 多模态消息）
- Web Speech API（语音输入 / TTS，零密钥）

## 项目边界

这是一个个人产品项目，模拟访谈和测试数据仅用于展示产品方法，不代表真实商业上线结果。第一版暂不做自动发布、预算决策和多国家同时生成。
